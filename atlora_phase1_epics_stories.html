E-03 Authentication & authorization 5 stories
E-03-01

Integrate Clerk for agency admin authentication

Configure Clerk application, set up organization support (one org = one agency). Provision agency_admin and agency_staff roles.

auth
E-03-02

JWT validation middleware in apps/api

Verify Clerk JWTs on every protected tRPC request. Extract agency_id and user role from the token and attach to context. Reject invalid or missing tokens with 401.

api
E-03-03

Role-based procedure guards in tRPC

Implement protectedProcedure and adminProcedure middleware that checks roles from context before resolving. All write procedures require at minimum agency_staff.

api
E-03-04

Seed Agency record tied to Clerk org on first login

On a new agency admin's first authenticated request, upsert an Agency row using the Clerk org ID as the external key. This is the multi-tenancy anchor.

apidb
E-03-05

Basic admin shell in apps/admin (login-gated)

Scaffold the Vite + React admin app with Clerk's React SDK. Show a sidebar nav behind auth. All routes redirect to Clerk's sign-in if unauthenticated.

webauth
E-04 Geography domain (countries, regions, destinations) 7 stories
E-04-01

Prisma schema: Country, Region, Destination

Define models with agency_id FK, slug, name, description, hero image URL, and status (draft/published). Add foreign key relations and run migration.

db
E-04-02

tRPC router: Country CRUD

Procedures: list (public), getBySlug (public), create, update, archive (admin-only). Input validated by Zod schemas in packages/types.

api
E-04-03

tRPC router: Region CRUD

Same shape as country router. Region has a many-to-many with Countries.

api
E-04-04

tRPC router: Destination CRUD

Destination belongs to a Country. Procedures include paginated list with optional country filter, getBySlug, create, update, archive.

api
E-04-05

Admin UI: Destinations list and create/edit form

Table of destinations with status badge, search, and create button. Create/edit form with slug auto-generation from name.

web
E-04-06

Public site: destination index page

/destinations — ISR grid of published destinations using DestinationCard from packages/ui. Revalidates every 60s.

web
E-04-07

Public site: destination detail page

/destinations/[slug] — SSR destination page with hero image, description, and linked trips. Returns 404 for unpublished slugs.

web
E-05 Trips domain & public website 7 stories
E-05-01

Prisma schema: Trip

Fields: agency_id, slug, title, tagline, description, price, duration_days, max_capacity, departure_date, status. Belongs to Destination.

db
E-05-02

tRPC router: Trip CRUD

list (public, filterable by destination and status), getBySlug (public), create, update, publish, archive. Pagination via cursor.

api
E-05-03

Admin UI: Trips list and create/edit form

Table with status, destination, price, departure date columns. Form includes rich text description field. Publish/unpublish toggle.

web
E-05-04

Public site: trips index page

/trips — ISR grid of published trips. Filter by destination via query param. Uses TripCard component.

web
E-05-05

Public site: trip detail page

/trips/[slug] — SSR trip detail page with hero, description, itinerary highlights, pricing, and a CTA to inquire. 404 for unpublished.

web
E-05-06

Public site: marketing home page

Hero section, featured destinations row, featured trips row, brand value props. ISR. Pulls featured content from API via a featured flag.

web
E-05-07

Public site: static marketing pages (About, Contact, Services)

Statically rendered. Contact page has a basic inquiry form that submits as a guest (no auth). Form posts to a tRPC mutation — data stored for Phase 3 lead management.
